# Investime

Sistema web para controle pessoal de investimentos, com foco em mobile first, organização financeira e evolução para um produto completo no estilo Kinvo, Status Invest e TradeMap.

## Estrutura

- `apps/web`: frontend em React + TypeScript + Vite + Tailwind
- `apps/api`: backend em Node.js + Express + JWT
- `packages/shared`: tipos e utilitários compartilhados
- `db/migrations`: estrutura PostgreSQL em SQL

## Módulos previstos

- autenticação completa
- dashboard inteligente
- carteira consolidada
- cadastro de investimentos
- dividendos
- aportes
- metas financeiras
- simuladores
- relatórios
- histórico de movimentações
- configurações e perfil
